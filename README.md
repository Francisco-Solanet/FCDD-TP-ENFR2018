# Análisis de la Encuesta Nacional de Factores de Riesgo 2018

## Descripción

Trabajo práctico realizado para la asignatura Fundamentos de Ciencia de Datos.

El proyecto desarrolla un análisis exploratorio de datos de la
Encuesta Nacional de Factores de Riesgo (ENFR) 2018.

## Objetivos

- Analizar características sociodemográficas.
- Estudiar hábitos y factores de riesgo.
- Analizar indicadores de salud.
- Formular y evaluar hipótesis mediante técnicas estadísticas.

## Estructura del proyecto

- notebooks/: análisis desarrollado en Google Colab.
- src/: código fuente desarrollado en Python.
- data/: conjuntos de datos utilizados.
- informe/: informe final del trabajo.

## Tecnologías utilizadas

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## Ejecución

Instalar las dependencias mediante:

pip install -r requirements.txt

Abrir el notebook ubicado en notebooks/ para reproducir
el análisis.
